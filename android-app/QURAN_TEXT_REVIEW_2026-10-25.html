Differences from the Quran tab’s scans

Q01 · Implemented 25 October 2026

Typed Quran and Hifz text now includes the scan’s stop signs

Fixed. The description and code excerpts below record the original review finding. See the implementation section above for the current result and validation.

The main Quran page is a scan and keeps its marks. Search results, the enlarged «اعرض النص» view, repeat previews and Hifz word text use the converted text, which removes source stop signs and does not add the scan’s replacements. The dataset contains 4,305 signs in 2,630 verses that these typed surfaces cannot show.

This is intentional behavior documented in adhkar-sources.md:105, but it does not meet the requested exact-waqf match. It is not a newly introduced corruption of the Quran source.

The example loses ج after the opening letters and the paired dots after ريب and فيه. Scan file 001 confirms all three. Copy/share already uses the scan-derived signs correctly.

Recommended correction: reuse the existing verse/word-index waqf map when constructing visible Quran text and Hifz words. Preserve the existing word identities used by memorization tools. Keep source Maghribi stop marks excluded; use the scan-derived replacements.

Q02 · Implemented 25 October 2026

Adhkar explanation quotations now use the canonical mushaf text

Fixed. The description and code excerpts below record the original review finding. See the implementation section above for the current result and validation.

The explanation of «سبحان الله وبحمده عدد خلقه…» quotes the full verse الكهف 104 using ordinary Arabic orthography and marks. It is displayed unchanged in the ordinary UI font. Related quotations in the explanations of Ayat al-Kursi, Ikhlas, Falaq and Nas have the same issue.

قُل لَّوْ كَانَ ٱَ۬لْبَحْرُ مِدَادࣰا لِّكَلِمَٰتِ رَبِّى لَنَفِدَ ٱَ۬لْبَحْرُ قَبْلَ أَن تَنفَدَ كَلِمَٰتُ رَبِّى وَلَوْ جِئْنَا بِمِثْلِهِۦ مَدَدࣰا

Concrete differences include قُلْ لَوْ versus قُل لَّوْ (lam sukun versus assimilation shadda), and أَنْ تَنْفَدَ versus أَن تَنفَدَ (nun sukun notation). Ordinary alifs, small alifs, wasl and tanween also differ. This verse has no internal scan-mapped waqf sign; its main issue is rasm/dabt/font consistency.

Assessment: the quotation preserves the words. Conventional Arabic spelling is not, by itself, an incorrect Quran reading. It does fail an exact match to this mushaf.

Recommended correction: identify explicitly Quranic spans in explanations, source those spans from the canonical words and marks, and render them in the mushaf font. Preserve the surrounding explanation and attribution.

The exhaustive corpus checks prove consistency with saved sources and conversion logic. They do not constitute a new letter-by-letter visual proofreading of all 6,214 verses against all 603 Quran scan pages. The detailed visual work is restricted to the shared passages and named examples.

Android Kotlin compilation and focused deterministic content checks passed after implementation. No APK was assembled or installed, and no device or TalkBack check was performed. Font coverage and code-level checks do not establish tiny-mark readability or clipping at every device font size. User-created Quran text, editable mosque ticker text and the separate experimental qaloon-app corpus remain outside this review.

The original review was read-only. The authorized follow-up changed the typed Quran/Hifz display pipeline, added the generated explanation quotation registry and its Android span rendering, and added focused regression coverage. Concurrent workspace changes were preserved.
