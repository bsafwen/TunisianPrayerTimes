# Tunis La Marsa best-effort boundary candidates

This package contains only the selected red boundary vectors extracted from the pinned ISIE 2023 GeoPDFs. The PDFs show Google imagery in the background; no imagery is stored, traced, or embedded here. Each source review records identity evidence, extraction pins, map-label fit, and uncertainty. These electoral-map footprints are provisional and do not claim surveyed current legal imada boundaries.

The combined manifest includes the separately reviewed Taieb Mehiri package by reference and stages all three replacements through the generic geometry overlay builder.
